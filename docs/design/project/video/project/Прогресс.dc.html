Шапка (ответ на вопрос 1) — 96 dp вместо заголовка 31 dp: строка «аватар 56 · имя + сумма часов 24 sp primary · ряд трофеев 3×32» и под ней полоса 6 dp со строкой «Уровень 4 · Первая позиция — до 5 уровня 8 ч 20 мин». Сумма часов — главное число шапки: единственный primary-текст на экране, имя стало подписью к нему. Итого экран вырос на 63 dp, календарь целиком остаётся на первом экране (нижний край легенды ≈ 690 dp из 788 доступных). Отдельный ряд трофеев не нужен: три значка живут справа от имени; при крупном шрифте (×1.5) или имени длиннее ~12 символов ряд ужимается до двух значков + «+1», в landscape — до строки «2 трофея · следующий 50 ч» (11g). Тап по аватару/имени → лист «Профиль», по ряду трофеев → лист «Трофеи». Полоса (вопрос 3) — тонкая, без процентов и очков: трек surfaceContainerHigh, заливка practice.3→primary; подпись говорит временем, как всё в «Занятиях». Уровень — в подписи onSurfaceVariant, не акцентом. Сумма часов — главное число шапки: единственный primary-текст на экране, имя стало подписью к нему. Аватар без имени (вопрос 5) — силуэт не нужен: круг surfaceContainerHigh с номером уровня, вместо имени — подпись «За скрипкой» над суммой. Полученные и неполученные (11e) различаются формой: полученные — цветная заливка «материалом», неполученные — контур outlineVariant без заливки; вдобавок текст статуса. Отметки 2500+ вынесены под разделитель «Далеко впереди» без остатка часов — только сама отметка: горизонт, а не долг. Предложение поведения: остаток часов показывать только для ближайшей неполученной, остальным — «—»; согласуем отдельно. Подарок (вопрос 4) — иллюстрация 160 dp scale .88→1 + fade 400 мс, за ней мягкое свечение primary 22 % проявляется 600 мс с задержкой 200 мс. Никаких частиц и звука; одна кнопка. В ряду шапки новый трофей после «Спасибо» появляется scale 0.6→1 250 мс на месте бывшего контура.

Ответ на вопрос 2. Один ряд предметов — от расходника к инструменту: канифоль → колок → струна → смычок → подбородник → камертон → пюпитр → футляр → скрипка → концерт (скрипка со смычком в золотом круге). «Вес» растёт материалом: канифоль и дерево → эбен → серебро и сталь → лак и золото. Всё построено из примитивов (rect, circle, ellipse, path с 2–4 точками) в viewBox 64×64 — переносится в VectorDrawable без упрощения; источник — массив TROPHIES в логике этого файла. Неполученный вариант — те же примитивы с fill surfaceContainer и stroke trophy.locked 1.5 — читается как «место под предмет».
