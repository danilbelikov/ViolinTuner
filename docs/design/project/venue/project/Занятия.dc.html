Клетка календаря — три независимых признака: заливка (ступень времени, 4 фиолетовых тона + точка под числом — форма для тех, кто не различает тон), «сегодня» — тонкое кольцо onSurface 1.5 dp, «выбранный» — внешнее кольцо primary 2 dp с зазором 2 dp; когда сегодня = выбранный, кольцо одно (primary), число жирное, а рядом с датой — чип «сегодня». Легенда «меньше — больше» четырьмя квадратами оставлена: без подписей и без чисел, чтобы не читалась оценкой.
