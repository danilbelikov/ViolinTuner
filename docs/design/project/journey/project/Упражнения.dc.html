Штили (вопрос 5) — четверти со штилями: штиль вверх у нот ниже средней линейки (позиция < 4), вниз — от средней и выше; звукоряд из головок выглядит как таблица, а со штилями — как строчка из сборника гамм. Вариант без штилей не рисуем отдельно — он равен эталонам минус штили. Перенос: ноты делятся между системами поровну по числу (43 → 15 · 14 · 14), а не «вверх / вниз»: разрыв на вершине оставляет вторую систему короче на одну ноту, а с sp 10 на пюпитре вершина всё равно не влезает в одну систему. Случайные знаки: правило состояния — знак ставится, когда высота ноты отличается от текущего состояния этой ступени в этой октаве (в начале гаммы состояние = знаки при ключе); состояние не сбрасывается на переносе системы — тактов нет, гамма одна фраза. Отсюда ♮ на спуске мелодического минора, даже если спуск начинается с новой системы. Правила
Тональность допустима при |fifths| ≤ 7, где fifths = F(буква) + 7·знак − (минор ? 3 : 0), F: F −1, C 0, G 1, D 2, A 3, E 4, B 5. Нижняя тоника — первая ≥ G3 (MIDI 55); октавы допустимы, пока тоника + 12·окт ≤ E7 (MIDI 100). Немецкие имена: диез «is», бемоль «es» (Es, As), B♭ → «B», B → «H», минор строчной. Уникальность гаммы — по (тоника, знак, вид, октавы). Выученным считается третий статус; дата перехода хранится; возврат в «Учу» убирает из счёта. Доли полосы — текущие статусы элементов раздела.
