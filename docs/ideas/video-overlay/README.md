# Идея: оверлей с нотами на видео-дубле

Статус: 2026-10-03 — по идее написаны спека `docs/spec/overlay.md` (0.89, 3.37, 5.30, этапы 123–126) и план `docs/plan-overlay.md`, макет в точных размерах — `docs/design/project/overlay/project/overlay.html`; открытые вопросы ниже решены там (вариант «Видео с нотами» в «Поделиться», первым и выбранным; кеш на час без второй копии; итог — 3 с после конца видео, всегда). Код не начат. Media3 Transformer 1.9.0 согласован владельцем.
Макет — `mockup.html` (варианты A–E; данные на нём выдуманные, фон — условная картинка видео).

## Идея
Снимаем видео-дубль. Когда дубль сохранён, приложение дорисовывает на видео оверлей с нотами, которые играл: как будто видео отредактировали после съёмки. Исходное видео не трогаем, оверлей — рендер по запросу («Поделиться», «Сохранить с нотами»).

## Выбрано (владелец): B + D
- **B. Лента нот** — ноты едут справа налево, как в караоке; высота = нота, цвет = зона (зелёный / янтарный / красный, как на Live); текущая нота у вертикальной черты; в углу бейдж «в строе N%».
- **D. Карточка итога** — последние 2–3 с кадр затемняется: «N% времени в строе», полоска зон на всю длину, лучшая нота, главный промах, сравнение с прошлым дублем, число тактов.

## Остальные варианты на макете (отложены)
- **A. Кривая высоты** — линия отклонения на фоне полосы допуска + текущая нота + полоска зон. Самый информативный, показывает вибрато и сползание.
- **C. Минимум для публикации** — бейдж пьесы, нота, полоска зон, без цифр.
- **E. Призрак прошлого дубля** — кривая A + бледная кривая лучшего дубля.

## Другие идеи оверлея (обсуждались, не рисовались)
- Метки промахов («+14 выше») только у заметных ошибок.
- Огибающая громкости под нотами (динамика, просадка смычка).
- Отметки пауз и смен смычка.
- Ритм относительно метроном/минусовки (приложение этого пока не знает).
- Бейдж в углу: пьеса, дата, серия дней, такты.
- Стили: минимальный, информативный, «для публикации».

## Технические заметки
- Данные: таймлайн разбора дубля (нота, центы, зона, громкость); ту же сглаженность, что на Live, использовать и здесь, иначе линия дёргается. Хранится ли таймлайн в нужном виде — не проверялось.
- Рендер уже есть для «Поделиться» (iOS — `AVAssetExportSession`, Android — свой рендер); оверлей — новый шаг в этом конвейере. С оверлеем картинку придётся перекодировать.
- iOS: `AVVideoComposition` + `AVVideoCompositionCoreAnimationTool` (слои `CALayer`).
- Android: Media3 Transformer с `OverlayEffect` — **новая зависимость, нужно согласие владельца** (правило CLAUDE.md); альтернатива без зависимости — `MediaCodec` + OpenGL, заметно дороже.
- Нужны прогресс и отмена: перекодирование минуты 720p занимает секунды–десятки секунд и греет телефон.
