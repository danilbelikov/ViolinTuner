# Заметки по коду · Знакомство (новый онбординг)

> Поведение — `docs/spec/onboarding.md` (3.33, 5.26) и `docs/spec.md` 3.7. Читай перед работой над этой фичей; дополняй здесь же.

Этапы 90–92 сделаны. На эмуляторе проверены: все семь экранов в портрете, landscape (знакомство и настройка), 360 × 640 с немецким, «назад» из настройки в знакомство, «Пропустить», свайп в обе стороны, разрешение микрофона, путь до «Занятий». На телефоне — нет; «убрать анимации» — только `@Preview` (превью все с `LocalReduceMotion = true`).

- **Шаг — один `OnboardingStep` из семи**, у каждого `part` (INTRO / SETUP) и `indexInPart`. Индекс шага лежит в `SavedStateHandle` (ключ `step`); старый индекс 0…2 из прежней версии читается как WELCOME…JOURNEY — безвредно. Переходы — чистый `OnboardingFlow` (`next`, `skip`, `back`, `swipedTo`), вьюмодель только зовёт его.
- **Пейджер и вьюмодель**: хозяин страницы — вьюмодель. Свайп → `snapshotFlow { settledPage }` → `PageShown`; смена шага кнопкой, «Пропустить» или «назад» → `LaunchedEffect(step)` двигает пейджер (соседняя — `animateScrollToPage`, дальняя — растворение: `fade` 1 → 0, `scrollToPage`, 0 → 1). Петли нет: совпавшая страница — no-op с обеих сторон.
- **Картинка — один `OnboardingArtCanvas` за пейджером**, а не в страницах: так у неба нет шва. Позиция пейджера, часы и высота картинки читаются в фазе рисования — перерисовка без рекомпозиции. В портрете высота — то, что оставил текст страницы (`Spacer(weight 1f)` меряется через `onSizeChanged` в карту `artHeights`), между страницами — линейно.
- **Сцены** — `art/OnboardingArtData.kt`, генерирует `node tools/onboarding/export.js` из `docs/design/project/new_onboarding/project/onboarding-art.js`. Руками не править: поменялся хэндофф — перезапусти скрипт. Телефон на пюпитре выгружен один раз с `zone` вместо цвета и со всеми тремя знаками; цвет и видимый знак — `LiveDemo` по времени страницы.
- **Стрелки 36b — как на Live**: «выше» (янтарный) — `mark:up`, «ниже» (красный) — `mark:down`. В хэндоффе было наоборот; маппинг — в `ArtMotion.parse`.
- **Время страницы** — от момента, когда она стала `settledPage` (`starts` в канвасе); вернулись на страницу — однократные движения идут заново. Поворот экрана пересоздаёт канвас, часы начинаются с нуля.
- В сцене `data` хэндофф хотел сдвинуть телефон на 22 вниз (`sh(...)`), но его поиск папки (`startsWith('M286 384')`) ничего не находит — сдвиг не срабатывает ни в макете, ни у нас. Кадры совпадают с макетом; если дизайн починит — перевыгрузить.
- **Строка статистики на 36d не показана** — сбора статистики ещё нет (спека, 3.33). Когда появится `analytics`: строка в `DataRows` (`OnboardingParts.kt`), тексты на десяти языках, иконка.
- Иконки строк: `AppIcons.Tape` (кассета контуром — штриховая версия вкладки «Записи») и `AppIcons.Takt` (знак такта) — новые в наборе; `AppIconsTest` считает набор (66).
- Цвет неактивной точки — `ViolinTheme.onboardingDotIdle` (#4A4760); цвета сцен — данные хэндоффа, не токены темы.
- Проверка на эмуляторе: `pm clear com.violinjourney.app.debug` (**только эмулятор**), первый старт после `pm clear` на этом эмуляторе ~25 с. Эмулятор рисует картинку ~5 кадров в секунду — цикл цвета на 36b ловится серией `screencap` с шагом 2 с. Язык — `adb shell cmd locale set-app-locales com.violinjourney.app.debug --locales de`, вернуть — `--locales ""`.
