# Заметки по коду · Тихие записи

> Перенесено из `CLAUDE.md` дословно. Поведение — `docs/spec/records2.md`. Читай перед работой над этой фичей; дополняй здесь же.

Этапы 45–47 сделаны — план и отклонения в `docs/plan-records2.md`. Не проверено: рост столбиков глазами, «убрать анимации» на графике, режим выбора с заголовками дней руками, записи прошлого года, TalkBack, телефон.
- **На карточке записи нет ничего про качество**: ни балла, ни цвета зоны, ни мини-столбиков, ни смещения, ни пресета звука (spec 3.21). `RecordTile(hasAudio, hasVideo)` — нейтральный круг 40 dp: `NoteOne` или `Video`, без звука — контур. Не возвращай зону «для наглядности». Балл живёт на экране записи, в прогрессе дублей и в тексте «Поделиться».
- `HistoryCard`: `date`, `otherYear`, `pieceId` (`take` — производное), `best`; `DayLabel`, `scoreZone`, `previewZones`, `biasCents` удалены. `previewZones` и смещение в базе и домене остались — схема сессий не менялась.
- **Дата один раз.** В «Записях» и «Записях этого дня» название — своё / произведение / «Запись», строка — «18:42 · 8:15» (`SessionCard`; диктору карточка говорит и дату — `RecordCard(spokenDate)`; с этапа 111 (3.36.5) карточка — одно описание «вид, «лучший», название, дата, время, длительность, «под минусовку», «без звука»», а плитка и тексты молчат — `docs/notes/redesign.md`, «Этап 111»; TalkBack и VoiceOver вживую не проверены); с этапа 111 в конце строки — слово вида («· дубль», «· видео», «· без звука», знак и «под минусовку»: `RecordLine`, `RecordPlace`); в списке дублей название — дата, у переименованного дата уходит в строку (`TakeCard` в `TakeBlocks.kt`). `sessionTitle(...)` с датой — только экран записи и имя файла. Форматы — `Formats.recordDate`, `Formats.recordDayHeader` (год — если не текущий).
- Вставки с датой — `HistoryState.groups`, производное от `cards`: выбор нескольких по-прежнему работает с плоским списком, заголовки не выбираются и не приглушаются. Крупного заголовка вкладки до spec 0.79 не было — его место занимал переключатель «Записи | Репертуар»; с этапа 100 (3.36.1) переключателя нет, а заголовок — «Записи» (`TabTitle`, строка `nav_history`; `docs/notes/redesign.md`). В landscape полоска (с этапа 111 — полоска «За две недели» вместо графика) — в левой колонке 360 dp (не шире половины окна за вычетом полей, `HistoryColumns`) вместе с заголовком и чипами, а не элемент списка.
- График (с этапа 111 — полоска: поле 28, столбики через 4 во всю ширину, без числа над столбиком, итог справа от «За две недели», 5.29 R5) — `DailyChart` + чистый `DailyChartMath` (тесты), домен — `RecordDays` (`core/domain/session/RecordDays.kt`; там же `HistoryWeeks`, от которого остался только `weekStartOf`), числа — `IntonationConfig.historyChartDays` / `historyChartMinTop`. Столбики растут один раз за жизнь графика в списке: флаг `grown` — `rememberSaveable`, ставится в начале роста, так что прокрутка туда-обратно (график — элемент `LazyColumn`, ушедший за экран выходит из композиции) и возврат с экрана записи рост не повторяют (27.09.2026, spec 5.15); «убрать анимации» — `LocalReduceMotion`, его ставит `HistoryRoute`.
- **«Лучший» — отметка человека, не балл**: `pieces.bestTakeId` (база v7, `MIGRATION_6_7`, без внешнего ключа). Читать только через `PieceStats.bestOf` — отметка на удалённый или чужой дубль значит «лучшего нет»; порядок списка — `PieceStats.listed` (лучший первым, остальные новые сверху). `RepertoireRepository.setBestTake(pieceId, sessionId?)` «активность» произведения не двигает. В строке прогресса наибольший балл — «максимум» (`maxScore`).
- Три входа: `HistoryIntent.BestToggled`, `PieceIntent.BestToggled` (меню «⋯», `CardActions.onBest`) и `SessionIntent.BestClicked` (звезда в шапке записи; `SessionEffect.ShowBestMarked(moved)` → тост, снятие — молча). «⋯» есть у каждого дубля, и без звука; с этапа 111 (3.36.5) — у каждой карточки с действиями, и у свободной записи без звука: у неё одно «Удалить…» без черты (`CardActions.onDelete`, `SelectionIntent.DeleteOneClicked`).
- «Записи этого дня» знают произведения: `PracticeViewModel` берёт `RepertoireRepository`. `PieceViewModel.takeSounds` удалён вместе с пресетом в строке дубля.
- Отмеченная карточка встаёт первой без анимации перестановки: список дублей — обычная колонка в прокручиваемом экране. Сообщение об отметке — тост, снекбара в проекте нет.
- Иконки: `NotePair` удалён, `StarOutline` добавлен — по-прежнему 55 + 4.
