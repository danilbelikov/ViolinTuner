# Заметки по коду · Иконки и движение «Занятий»

> Перенесено из `CLAUDE.md` дословно. Поведение — `docs/spec/polish.md`. Читай перед работой над этой фичей; дополняй здесь же.

Этапы 25–27 сделаны — план и отклонения в `docs/plan-polish.md`. Не проверено глазами в движении (скриншоты ловят кадры покоя): проход блика, дыхание точки, докрутка чисел, «убрать анимации» на «Занятиях»; телефон.
- Набор иконок — `core/ui/icons`: `IconPaths` (строки `d` из массива `ICONS` хэндоффа, **сгенерированы скриптом** — иконку меняют в хэндоффе и перегенерируют, а не правят путь руками; префикс `F ` — заливка без обводки), `AppIcons` (`ImageVector` по требованию через `PathParser` из Compose — библиотеки иконок по-прежнему нет), `AppIcon(icon, contentDescription, size, tint)`, `IconLabel` (иконка + текст внутри обычной Material-кнопки; цвет берёт у кнопки — для другого цвета оборачивай в `LocalContentColor`), размеры — `IconSizes` (24 / 18 / 20 / 14 dp). `AppIconsTest` строит каждую иконку на JVM.
- Вкладки — `TabIcon(normal, selected, selectedCut)`: выбранный значок — залитое тело плюс деталь («стрелка» секундомера) отдельным слоем цветом пилюли: иконка одноцветная, «прорезать» иначе нечем. `ic_nav_*.xml` удалены, `TopLevelDestination` про значки не знает — их выбирает `AppBottomBar`.
- Иконка рядом с подписью — `contentDescription = null`, одиночная — с описанием. Деструктивное — `ViolinTheme.destructive` (корзина и текст вместе); `formError` остался у формы, цвета зон — только про интонацию. В залитых главных кнопках иконки нет, кроме «Начать занятие» (секундомер); «Закончить» — флажок: треугольник, квадрат и круг заняты плеером и записью.
- Намеренно не из набора: замок струны на Live (залитый глиф 12 dp), ▶ / ❚❚ плеера (залитые на акцентной кнопке), стрелки статуса Live, кнопка записи, точки состояния. Темп — `KeyAndTempo` (метроном 14 dp + число; в форме крупное «♩ = 96» осталось).
- «Убрать анимации» для декоративного движения — `LocalReduceMotion` (`core/ui/motion`), ставит `PracticeRoute` через `rememberAnimationsRemoved()`; компоненты спрашивают его сами. У Live по-прежнему свой параметр `reduceMotion`.
- Блик полосы уровня — `LevelShine` + `rememberLevelShine(filled, enabled)`: один долгоживущий цикл, между проходами спит на `delay` (кадров не тратит), кадрами шагает только сам проход; рисуется в `drawBehind` полосы внутри `clipPath` заливки — шапка не перекомпоновывается. Уступает движению полосы (`filled.isRunning`): не стартует, бросает начатый проход, следующий — через `AFTER_GROWTH_MS`. Правила — чистый `LevelShineMath` (ширина полосы света, путь, длительность ∝ пути, «блика нет» при заливке < 12 dp) с тестами.
- Цвет блика — `LevelShine` в `Color.kt`, намеренно ярче макета (α .8 против .35: на светлом конце заливки макетный не виден). Скриншотом блик почти не поймать (проход 1.2 с из 4): снимай `adb shell screenrecord --time-limit 9`, кадры доставай Swift-скриптом на `AVAssetImageGenerator` (ffmpeg на машине нет) и сравнивай строку полосы с кадром покоя.
- `RunningDot(elapsedMs, …)`: дыхание — `rememberInfiniteTransition` (цель постоянна, это можно), дуга — угол от секунд таймера, между тиками доводится кадровым циклом; всё читается в `drawBehind`. Кадры идут только пока занятие идёт и экран в композиции.
- `rolledValue(target, scope, …)`: первое значение берётся как есть, новый `scope` (месяц календаря, конец загрузки) начинает заново — поэтому загрузка, возврат на вкладку и смена месяца числа не гоняют. Читает значение в композиции — карточка перекомпоновывается 600 мс на перемену, это принято.
- Скрипты правок Kotlin лежат вне репозитория; если понадобится перегенерировать иконки — разобрать `const ICONS = [` в `Иконки и жизнь.dc.html` (имя → `UPPER_SNAKE`, у вкладок `sel: fill / inv` → `Selected.FILL / CUT`).
