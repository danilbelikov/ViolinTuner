# Заметки по коду · Видео-дубли

> Перенесено из `CLAUDE.md` дословно. Поведение — `docs/spec/video.md`. Читай перед работой над этой фичей; дополняй здесь же.

Этапы 36–40 сделаны — план и отклонения в `docs/plan-video.md`. Не проверено: съёмка системной камерой руками (`CaptureVideo`; проверен путь «из галереи»), вертикальное видео, потерянный и недекодируемый файл глазами, вопрос «Остановить разбор?» руками, синхронность на глаз и слух, прилипание на телефоне, TalkBack.
- Слова: «видео-дубль» — дубль с картинкой, та же сессия; третьей сущности нет. **Звук видео-дубля — дорожка самого файла**: `audioPath` и `videoPath` сессии — одно имя `.mp4`, отдельного `.m4a` нет. Поэтому плеер, форма волны, «Звук», рендер и удаление работают без правок, а потерянный файл = нет ни картинки, ни звука.
- Разбор — `core/recording`: чистый `TakeFileAnalysis` (`PcmSource` → целые хопы по 512 → `FrameAnalyzer` → движок → `SessionRecorder`; первым идёт `Silence` с `tMs = 0`, чтобы ноты встали на время файла) и `DecodingFileTakeAnalyzer` поверх `PcmDecoder`. Декодер отдаёт куски как придётся — без пересборки в хопы результат отличался бы от микрофонного; это сторожит `TakeFileAnalysisTest`. Скорость на эмуляторе — 2.9× (`adb logcat -s FileTakeAnalysisSpeed`).
- `core/recording/video`: `VideoFiles` / `AppVideoFiles` (те же `files/sessions/`, рядом `<uuid>-thumb.jpg`; съёмка — в `cache/camera/` и сразу перенос переименованием), `VideoDates` (дата из метаданных; 1904 год — «даты нет»), `VideoTakeImporter` — **синглтон со своей областью**: уход с экрана разбор не рвёт, экран только смотрит на `state` (`VideoImport.Idle / Working / Failed`) и `saved`. Один импорт за раз. «Остановить разбор?» — флаг `asking`, разбор идёт под вопросом.
- `AppSessionAudioFiles.delete` уносит и миниатюру; чистка сирот даёт всему, что не `.m4a`, сутки (`RepertoireConfig.orphanVideoMinAgeMs`). Интерфейс `SessionAudioFiles` не менялся намеренно — у него пять тестовых фейков.
- База v6: `sessions.videoPath` (`MIGRATION_5_6`, один `ALTER TABLE`). `DatabaseMigrationTest` стартует с v1–v5; v5 раскладывается руками из `DatabaseMigrations.SOUND_COLUMNS` (он `internal` ради этого).
- Лист разбора (`VideoTake.kt`) не закрывается свайпом через `confirmValueChange = { it != SheetValue.Hidden }` — **не `{ false }`**: тот запрещает листу и раскрыться.
- Картинка — `core/audio/playback/VideoTrackRenderer` (за `VideoPicture`): свой поток, `follow(positionMs, playing)` на каждое слово плеера (~43 мс), между словами время несётся монотонными часами не дольше 500 мс. Кадр показывается, когда звук дошёл до его времени; опоздавший > 50 мс отбрасывается; прыжок звука — перемотка к опорному кадру с докруткой без показа. Плеер не менялся.
- **Кодек нельзя `flush()`-ить до его первого выхода** — он теряет SPS/PPS, и аппаратный декодер падает на каждом кадре; программный прощает, поэтому тест этого не ловит. **Буфер нулевого размера при выводе на поверхность — это кадр**, пустой только голый маркер конца потока. Аппаратный декодер эмулятора не рисует в `ImageReader` — у рендерера есть `softwareDecoder` только для `VideoPlaybackTest` (кадр узнаётся по яркости, `TestVideo.lumaOf`).
- `VideoSurface` (`feature/session/components/VideoBlock.kt`) — `TextureView` в `AndroidView`, **единственный View-интероп проекта**. Полный экран — состояние того же экрана (`SessionState.fullscreen`), вид там другой, и новая поверхность может прийти раньше ухода старой: `SessionViewModel.attachSurface / detachSurface` сверяют поверхность по идентичности.
- Раскладка — чистый `VideoLayoutMath` (блок ≤ 40 % экрана, сжатие в строку 72 dp по смещению прокрутки, окно полоски нот ±4 с). Запасной вариант без прилипания — `VIDEO_STICKS = false` в `SessionScreen.kt`.
- «Поделиться»: `SoundRenderer.renderVideo` — звук существующим `render` во временный `.m4a`, затем `MediaMuxer` копирует видеосэмплы как есть; при нейтральных настройках `render` цепочку не вызывает. У видео-дубля лист показывается всегда (`ShareVariant.SOUND` — третий вариант). Оригинал отдаётся жёсткой ссылкой (`Os.link` в `AppShareFiles.original`), копия — запасной путь.
- `ElapsedClock` живёт в `core/di` (нужен импортёру); `Formats.fileSize` — «214 МБ», «1,5 ГБ».
- Проверка на эмуляторе: пробное видео делает `androidTest/.../testing/TestVideo` (яркость кадра = номер кадра, звук — тон заданной высоты); чтобы положить его в галерею — временный тест, пишущий в `getExternalFilesDir`, затем `adb shell cp` в `/sdcard/Movies` и `MEDIA_SCANNER_SCAN_FILE`. `AVAssetWriter` на хосте для этого не годится — зависал. В системном пикере видео выбирается тапом по описанию («duration 00:40») и «Done».
