# Заметки по коду · Разделы репертуара и гаммы

> Перенесено из `CLAUDE.md` дословно. Поведение — `docs/spec/exercises.md`. Читай перед работой над этой фичей; дополняй здесь же.

Этапы 48–51 сделаны — план и отклонения в `docs/plan-exercises.md`. Не проверено: свои разделы руками (есть тесты), формы этюда и штриха глазами, мелодический минор и бемольные тональности глазами (есть тесты раскладки), свёрнутая длинная гамма, фото под нарисованной гаммой, запись дубля гаммы, landscape, TalkBack, телефон.
- **Раздел — папка, не сущность**: этюд, штрих и гамма — тот же `Piece`. Готовые разделы в базе не лежат: `pieces.section` (имя `PieceSection`, по умолчанию `PIECES`) + `pieces.groupId` своего раздела (`piece_groups`, без внешнего ключа). Где живёт элемент — только через `PieceRules.sectionOf`: группа, пока она существует, иначе встроенный раздел. Счёт и порядок разделов (готовые, затем свои по алфавиту) — `SectionStats`. Удаление своего раздела — транзакция `RepertoireDao.deleteGroup`: элементы уезжают в `PIECES`.
- Гамма — `Piece.scale: ScaleSpec?` (тональность в прежних столбцах ключа + `scaleKind`, `scaleOctaves`). `PieceRules.clean` не пропустит гамму вне «Гамм» и не-гамму в «Гаммах». Такая же гамма второй раз — `SectionStats.sameScale`. **Название гаммы хранится как обычное название** (оно нужно «Записям» и «Поделиться»), собирает его `ScaleTexts` (ресурсы; в тестах фейк); меняешь слова — старые гаммы останутся со старыми названиями до правки.
- День выученного — `pieces.learnedAtEpochMs`, ведёт DAO в одной транзакции со сменой статуса (`settleLearned`); на экране его пока нет — макет заменил график по месяцам полосой долей (`SectionBar`). База v8 (`MIGRATION_7_8`: пять `ALTER TABLE`, таблица `piece_groups`, день выученного = время правки у уже выученных).
- «Выучено» вместо «В репертуаре» в «Гаммах», «Этюдах», «Штрихах» — один статус в данных, слово выбирает `LocalExerciseWords` (CompositionLocal; ставят `SectionScreen`, `PieceScreen`, обе формы). Новый экран со статусом обязан его поставить, иначе будет «В репертуаре».
- Домен гамм — `core/domain/repertoire/scale`, чистый Kotlin: `Scales` (знаки тональности `fifthsOf`, допустимость ≤ 7 знаков, нижняя тоника ≥ G3, октавы до E7, построение: буква следует за буквой, энгармонических замен нет), `ScaleNote.position` — шаги стана от нижней линейки (E4 = 0, средняя линейка — 4), `ScaleEngraver` → `Engraving` (системы, знаки при ключе, случайные знаки, штили, добавочные, 8va). `ScaleEngraverTest` перебирает все тональности, виды, октавы и пять ширин.
- **Случайные знаки — по состоянию ступени в её октаве, без сброса на переносе системы** (тактов нет): отсюда бекары на спуске мелодического минора. **Ноты делятся между системами поровну**, а если ровная доля не влезает по ширине — систем становится больше и деление повторяется: одинокой ноты в хвосте не бывает (поймано на gis-moll в три октавы). Системе с «8va» добавляется `OTTAVA_ROOM` сверху: пять добавочных занимают весь обычный запас (тоже поймано на экране; в макете этого нет).
- Отрисовка — `feature/repertoire/scale`: `NotationMetrics` (всё в долях расстояния между линейками — лист метрик хэндоффа), `NotationGlyphs` (пути ключа, ♯ ♭ ♮ 𝄪 **строками из хэндоффа** — знак меняют там и копируют сюда; ключ обводится, остальное заливается; головка — повёрнутый овал), `ScaleNotation(scale, space, ink, maxSystems)`, `KeySignatureTile`. Размер — `NotationSizes` (карточка 7.5 dp, пюпитр 10, форма 7, плитка 4.5). Чернила — `ViolinTheme.exerciseColors.inkOnDark / inkOnPaper`. Нотных шрифтов и библиотек нет и не будет.
- Экран гаммы — тот же `PieceScreen`: `PieceState.scale` → `DrawnScale` первым в блоке нот (до трёх систем целиком, дальше две и «ещё N систем»), под заголовком вид гаммы вместо композитора. **Нарисованная страница — страница 0 пюпитра** (`StandPage.scale`, id `DRAWN_ID`, без корзины), фото идут с индекса 1 — `PageClicked(index + 1)`. Пюпитр гаммы без фото не закрывается.
- Экраны: вход — `sectionItems` в списке вкладки «Записи» (`SectionsViewModel`; новый раздел сразу открывается), список раздела — `SectionRoute` / `SectionScreen` на прежних `RepertoireViewModel` + `repertoireItems` (ключ раздела — `SectionKeys`: имя встроенного или `g<id>`), форма гаммы — `ScaleFormViewModel` (тональность и вид существующей гаммы заблокированы → `ShowLocked`; недопустимая тоника снимается, лишние октавы опускаются — `fitted`). У `pieceForm` аргумент `section`; перенос в «Штрихи» стирает автора и тональность — форма их там не показывает.
