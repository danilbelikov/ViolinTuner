# Заметки по коду · Путешествие

> Перенесено из `CLAUDE.md` дословно. Поведение — `docs/spec/journey.md`. Читай перед работой над этой фичей; дополняй здесь же.

Этапы 52–55 сделаны — план и отклонения в `docs/plan-journey.md`. Не проверено: телефон и живой инструмент (сколько тактов даёт настоящее занятие), движение открытки глазами и щипок в полном экране, landscape, таблетка «+N тактов» глазами, дорога кораблём и самолётом, «убрать анимации», TalkBack.
- Слова: «такт» — валюта, «остановка» (`JourneyStop`), «открытка» (сцена), «дорога», «паспорт». Путешествие — не оценка: такты не отнимаются, цветов зон в нём нет (краски штампов — `stampInk`, четыре по кругу). **На Live ничего про такты не появляется** — ни счётчика, ни «+1».
- Домен — `core/domain/journey`, чистый Kotlin: `JourneyConfig` (курс и цены дополнений), `JourneyRoute.stops` (цены, транспорт, точка на карте, `available`, `views`), `JourneyProgress` (баланс не хранится: заработано − потрачено), `JourneyRules` (`next`, `missing`, `canDepart`, `offers`, `canBuy`), `JourneyRepository`. Сумма цен — 81 900 (в макете названо 81 700 — это опечатка макета).
- **Такты считает конвейер, не экран**: `NoteCounter` в `TakePipeline.run` рядом с движком (нота ≥ 200 мс; «в строе» — большинство свежих показаний в зелёной зоне; `held` не считается), только при идущем занятии; счёт дописывается в `PracticeNotesStore` (DataStore, ключи `practice_notes_*`, привязан к началу занятия) раз в 10 с по `tMs` и в `onCompletion`. У новых параметров конструктора значения по умолчанию (`NoPracticeNotes`) — тесты конвейера не менялись.
- **Начисляет только `PracticeFinisher.save`** (ноты × 1 + целые минуты × 2 → `TaktEarning`), `discard` стирает счёт. «Изменить время» идёт мимо и тактов не даёт намеренно; видео-дубли (разбор по файлу) — тоже.
- База v9 (`MIGRATION_8_9`): `journey_earnings`, `journey_arrivals`, `journey_extras`; цена пишется в строку покупки; отправление и покупка — транзакции `JourneyDao` «проверить баланс → вставить». `DatabaseMigrationTest` стартует с v1–v8. Копия данных подхватывает сама.
- **Сцены открыток сгенерированы**: `assets/journey/<сцена>.<eve|day>.scene` (строка на слой, табуляция) пишет `node tools/journey/export.js [папка предпросмотра]`: он вырезает помощники, сцены и силуэты из JS хэндоффа и добавляет сцены, дорисованные после него, — `tools/journey/extra-scenes.js` (prague, leipzig, berlin, amsterdam, paris, spb, moscow, newyork, buenosaires, tokyo; те же примитивы `R / PG / ARCH / L` плюс свои `GROUND`, `palm`, `blossom`; виды снаружи `cremonaOut` / `milanOut`; движущиеся вещи — двенадцатое поле слоя `SceneAnim` (`ride` / `bob` / `bird` / `blink` / `fall`, через `+`; все слои одной вещи несут одно и то же и идут как один — `SceneMotion.moved`), строители `tramAt` / `busAt` / `taxiAt` / `sailboatAt` / `ferryAt` / `planeAt` / `flock`, в сцены хэндоффа их вставляет `EXTRA_INSERTS` (home, vienna, london, sydney, austria); обрезки в формате слоя нет — птицы гаснут у краёв своего пути; **строка слоя с литеральным цветом начинается с `#` — комментарий в `.scene` только «# …»** (на этом уже теряли слои); залы изнутри — сцены `<остановка>Int` из четырёх построителей `HALL` / `HORSESHOE` / `VINEYARD` / `NAVE` с опциями-приметами, палитры `INT_LOCPAL`, `aerial: false`; палитры — `EXTRA_LOCPAL`, из них экспортёр пишет `ExtraScenePalettes.kt`). Сцену меняют в хэндоффе или в `extra-scenes.js` и выгружают заново, руками `.scene` не правят. С папкой предпросмотра скрипт пишет SVG каждой сцены — смотреть без сборки: `qlmanage -t -s 824 -o . файл.svg`. Новое место = сцена + палитра в `EXTRA_LOCPAL` + `views` у остановки; руками в `ScenePalette.locations` — только палитры самого хэндоффа. `feature/journey/art`: `SceneParser`, `ScenePalette` (общая палитра времени суток + палитра места, токены `SKY` / `GLOW` — градиенты), `SceneCanvas` (`Postcard(stop, description, mode, inside)`: заполняет рамку с обрезкой по центру, воздушная перспектива — смешение с небом по глубине слоя, кеш подготовленных путей), `JourneySilhouettes` (штампы и открытка-эскиз у ненарисованных мест). `SceneTest` разрешает каждый токен каждой сцены и сверяет файлы с `views` маршрута — новая сцена без файла не соберётся.
- **Живая открытка и полный экран** (spec 0.42): `art/SceneMotion.kt` — чистые `SceneMotion` (слой движется по токену заливки: `window` / `windowLit` / `chandelier` мерцают, `GLOW` и `warmGlow` дышат, `waterLit` дрейфует; в сценах ничего не размечено — не хочешь, чтобы слой двигался, залей его литералом) и `SceneCamera` (масштаб «покрыть», зажим сдвига, параллакс по глубине 0.6 / 0.85 / 1; тест «ни один план не показывает край»), `rememberSceneSeconds` (≤ 30 кадров/с, null при «убрать анимации»). `Postcard(seconds, camera)` читает оба в фазе отрисовки. Живёт открытка везде, где она крупная (карточка на «Занятиях», экран путешествия, вступление, прибытие, остановка, полный экран) — решение владельца в 0.43, правило 3.16 о двух движениях её не касается; миниатюры ленты неподвижны. Звёзды и облака — не слои сцен, а правило (`SceneMotion.star / cloud`, над слоем `SKY`, только `aerial`). **Полный экран остановки держится в кадре сцены** (0.61) — `SceneFrame` (там же, в `SceneMotion.kt`): кадр из шапки файла (`frame=верх,низ`, пишет экспортёр: открытка 0…260, зал со сцены −240…480, место во весь экран — `frame: [-420, 600]` в описании сцены), `openZoom` — самый широкий вид, который кадр ещё закрывает, `originY` — полоса открытки посередине, сдвинутая не дальше кадра, `clamp`, `zoom`, `nextZoom`; тест «ни при каком масштабе и сдвиге не видно того, что не нарисовано» — на экранах телефона, маленького, лёжа и планшета. `Postcard(camera)` держит вид в кадре и при отрисовке: поворот и переключение вида меняют коробку и кадр раньше, чем жест. `zoom = 0` в `FullscreenPostcard` — «вид, которым открылось» (размер коробки известен только в жестах и в отрисовке); переключение «снаружи | внутри» сбрасывает камеру. Подсказка у места во весь экран — `home_fullscreen_hint`. `SceneCamera.wholeZoom / top / clamp` остались только дому: его камеру не трогали. До 0.61 отдаление шло до `wholeZoom` — открытка под пустым небом или на тёмном. Владелец уже раз не увидел слишком тихую анимацию — амплитуды в `SceneMotion` не убавляй без его слова. Полный экран — `StopState.fullscreen` + `FullscreenPostcard` (`JourneyFullscreen.kt`), не маршрут: «назад» сворачивает. На эмуляторе вход — тап по координатам открытки (у `onClickLabel` нет текста в `uiautomator dump`).
- **Лист проверки** — `tools/journey/sheet.js`: после `node tools/journey/export.js <папка>` пишет `<папка>/sheet.html` — каждый вид (снаружи и внутри, вечер и день) так, как его откроет полный экран на телефоне 412 × 915, маленьком 360 × 640 и лёжа, и рядом весь кадр сцены; где не нарисовано ничего — пурпур, страница считает его долю. Второй аргумент (`-420,600`) примеряет кадр на все сцены — показывает, чего не хватает для полного экрана. Счёт без окна браузера: Chrome `--headless=new --virtual-time-budget=60000 --dump-dom` и `grep -o 'id="report">[^<]*'`. Считает по SVG предпросмотра экспортёра: звёзд и облаков (их рисует правило) там нет.
- Нарисованы все 16 остановок и дом (spec 0.44), все `available`; у каждой остановки с видом снаружи есть второй вид — зал изнутри (0.45), у cremona и milan главный вид изнутри, второй — снаружи (0.46), у home второго нет; открытка-эскиз из силуэта осталась запасным видом для будущей остановки без картинки. У остановки без `views` нет дополнений с картинкой (`JourneyRules.offers`).
- Экраны — `feature/journey`: `JourneyViewModel` один на три вида (`JourneyView.MAIN / MAP / PASSPORT`, у каждого маршрута свой экземпляр), `StopViewModel` (`journeyStop/{stopId}`). **Дорога — фаза экрана** (`JourneyPhase.Road → Arrival → Stamp`), остановка оплачена и достигнута до неё; на дороге интенты молчат, «назад» проглатывает `BackHandler`. Пока экран покоя гаснет в `AnimatedContent`, он показывает прежнее состояние (`calm`) — иначе мелькает следующий город.
- Карта — `JourneyMapCanvas` + чистый `JourneyMapMath` (сетка 412 × 700, перегон Катмулла — Рома, `stopAt`, `clampPan`; тесты). Подписи рисуются в пикселях поверх — размер текста не зависит от масштаба. Обычная карта вписана целиком, дорога — ×1.8 на перегоне.
- Окно на «Занятиях» — `PracticeViewModel.journeyWindow` (отдельный поток) и слот `journeyCard` у `PracticeScreen`, **не поле `PracticeState`**. «+N тактов» — только для заработка, пришедшего при живом экране (первое значение — история).
