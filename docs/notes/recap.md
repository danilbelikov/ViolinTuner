# Заметки по коду · Итог занятия

> Поведение — `docs/spec/recap.md`. Читай перед работой над этой фичей; дополняй здесь же.

Этапы 82–84 сделаны — план и отклонения в `docs/plan-recap.md`. На эмуляторе проверены сохранение из листа итога в портрете и landscape и таблетка после «Готово»; диалог забытого занятия, подарок после итога, новый уровень и «хватает до …» — только тестами и `@Preview`. На телефоне — нет.

- **Домен — `core/domain/practice/PracticeRecap.kt`**, чистый: `RecapRules.of(earning, entries, journey, today, …)` строит итог из строки заработка и того, что уже лежит после сохранения («до» = «после» минус занятие). Занятие — последняя не ручная запись по началу. `RecapRoad`: `NotStarted` (вступление не пройдено), `Leg` (баланс до и после, цена), `RouteDone`.
- **Такты по источникам — `JourneyRules.taktsBySource`**: `taktsFor` теперь сумма его частей, так что лист и начисление не разойдутся. Правишь формулу тактов — правь там.
- **`PracticeFinisher.save` возвращает `TaktEarning?`** (null — занятия уже нет). Возвращённая строка равна той, что ляжет в базу (проверяет `PracticeEarnsTaktsTest`) — по этому равенству `PracticeViewModel` не открывает итог дважды.
- **Открывает итог `PracticeViewModel.openRecap`** с двух сторон: после своего `save` и из коллектора `journey.progress` (новая `lastEarning` — сохранили из диалога забытого занятия). Первая прочитанная строка — история. Итог встаёт на место листа итога (`Summary`) или на пустое место; поверх другого листа — только таблетка.
- **Порядок «итог → подарок → таблетка»**: подарок редьюсер и так даёт только без листа; таблетку (`earnedPill`) `showPill` включает, когда в `state` нет ни листа, ни подарка. `journeyWindow` — `combine` прогресса, места и таблетки, без собственного `delay`.
- **Лист — `feature/practice/components/RecapSheet.kt`**: одна `Animatable` на рост (такты докручиваются, полосы дорастают), своя — на переход уровня (полоса до конца, потом с нуля). `animated = false` — для превью, где первый кадр — всё, что есть. Низкое окно (< 520 dp) — два столбца.
- **Строки** — `recap_*`; «Готово» — `profile_done`, «В дорогу» — `home_travel`, «Репертуар» — `block_entry`, уровень — `progress_level` и `progress_to_next_level`.
- Проверка на эмуляторе: занятие → Live минуту (DEMO) → «Занятия» → «Закончить» → «Сохранить». Таблетка живёт 4 с, а `uiautomator dump` на этом эмуляторе идёт до 20 с — лови её серией `screencap` сразу после тапа по «Готово» координатами. Снимки отстают на несколько секунд: сверяйся с дампом.
