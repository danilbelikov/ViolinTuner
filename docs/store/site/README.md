# Violin Journey — site

The public pages of the Violin Journey app, served by GitHub Pages:

- `/` — what the app is, in Russian and English;
- `/privacy/` — the privacy policy the stores and the app's Settings link to.

The source lives in the app's repository, `docs/store/site/`; this repository is a copy of that folder.
Change the pages there and copy them over, never here only.
