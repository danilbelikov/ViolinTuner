# План реализации: иконки и живой экран «Занятий»

Поведение — в `docs/spec.md` (3.16, 5.10). Здесь — как это строится. Макет — `docs/design/project/polish/project/Иконки и жизнь.dc.html`: кадры 14a–14d (иконки), 15a–15b (экраны «после»), 16a–16b (блик), 17a–17d (живой таймер, ноты, клетка, докрутка), секция `dev` с массивами `ICONS`, `tokens`, `sizes`, `anims`.

## Что берём из макета и что меняем

| Из макета | Решение |
|---|---|
| Набор `ICONS`: 33 иконки, только `path`, префикс `F` — заливка без обводки, у вкладок `sel: fill / inv` | Берём целиком. Пути переносятся строками `d` и разбираются `PathParser` из Compose (он уже в зависимостях) — без ручной перепечатки в команды и без библиотеки иконок. Unit-тест строит каждую иконку: опечатка в пути ловится на JVM |
| Выбранная вкладка — заливка тела, деталь «прорезана» цветом пилюли | Берём. Иконка — одноцветная, поэтому выбранный значок — два слоя: тело (`onPrimaryContainer`) и прорезь (`primaryContainer`). `ic_nav_*.xml` удаляются |
| «Назад» 2.2 → 1.8 | Берём: один компонент вместо четырёх копий, нарисованных линиями |
| Иконка 18 dp слева от текста; у деструктивных — корзина + цвет ошибки; в залитых кнопках иконки нет, кроме «Начать занятие» | Берём. Токен `icon.error` не заводим: это уже существующий `formError` репертуара, он переезжает в общий токен `destructive` (тот же hex), чтобы сессия и профиль не брали цвет у репертуара |
| Старт — секундомер, стоп — флажок | Берём |
| Метроном вместо ♩, нота в чипе «дубль», звезда у «лучший», огонёк при серии ≥ 3, трофей в заголовке листа | Берём |
| «Настройки» — строки со значком, значением и шевроном, строка «Микрофон» | Не берём: экран настроек — два контрола на месте (spec 3.8), переходить некуда, строки «Микрофон» нет и не планируется (раздел 7). Иконки камертона и мишени встают перед заголовками разделов, «повтор» — в кнопку |
| Пюпитр: «Готово» → галочка | Нет такой кнопки: пюпитр закрывается «назад». Галочка остаётся в наборе (выбранный пункт меню статуса) |
| Иконка `more` у сворачивания заметок | Не берём: три точки обещают меню, а там раскрытие текста. Остаётся слово «ещё» |
| Иконка `stand` (не обязательна) | Не используем: входа «открыть пюпитр» отдельной кнопкой нет — открывает тап по миниатюре |
| «Трофеи 2 из 12» | Счётчик в заголовке не добавляем (в спеке его нет; отметок 10) — только иконка |
| Подложка кнопок-иконок пюпитра r24 rgba(19,19,24,.7) | Берём: на увеличенном светлом листе контуры терялись — это видели на эмуляторе |
| Блик: 56 dp, 4 с / 1.2 с, FastOutSlowIn, clamp на короткой заливке, пауза 1.5 с после роста, `level.shine` | Берём. Landscape отдельной длительностью (1.0 с) не задаём: формула «длительность ∝ пути» даёт её сама |
| Отрисовка блика — `withInfiniteAnimationFrameMillis` + `!isResumed` | Делаем своим кадровым циклом, как свечение кольца: `LaunchedEffect` с `withFrameMillis` на время прохода, между проходами — `delay` (кадров не тратит). Остановка вне экрана — сама: вкладка уходит из композиции, а в фоне кадровые часы Compose стоят |
| B — дыхание точки и минутное кольцо, фаза от секунд таймера | Берём. Угол считается из `timerMs` состояния, между секундными тиками доводится кадровым циклом |
| D — докрутка чисел, порог 5 мин | Берём, с уточнением: только при перемене на глазах (то же правило `armed`, что у шапки профиля) и не при смене месяца в календаре |
| A — ноты, C — клетка «сегодня» | Отклонены макетом; в спеке — раздел 7 |

## Решения, которых нет ни в спеке, ни в макете

- **`core/ui/icons`**: `AppIcons` (объект, иконки — `ImageVector` по требованию, `lazy`), `IconPaths` (строки из `ICONS`), `AppIcon(icon, size, tint, contentDescription)` и `IconLabel` (иконка + текст для кнопок — размеры из `sizes`). Вкладки — `TabIcons` с парой «обычная / выбранная + прорезь».
- **Кнопки**: общий `IconTextButton` / `IconOutlinedButton` не заводим поверх Material — достаточно `IconLabel` внутри существующих `TextButton` / `OutlinedButton`: отступы кнопок остаются Material, меняется только содержимое.
- **Нарисованные по месту значки** (`drawBackArrow`, `drawBin`, `Chevron`, `ClockIcon`, замок, шевроны календаря, плеер) заменяются на набор; `Arrow` статуса Live, кнопка записи и точки состояния — не иконки, остаются.
- **Движение** — в `feature/practice/components`: `LevelShine` (математика блика — чистый `LevelShineMath` с тестами: ширина, путь, длительность, «нет блика»), `LiveTimerDot`, `RollingMinutes`. Числа — `ProgressMotion` (блик) и новый `PracticeMotion`.
- **«Убрать анимации»**: `PracticeRoute` читает `ANIMATOR_DURATION_SCALE` на `ON_RESUME`, как `LiveRoute`, и отдаёт `reduceMotion` экрану.

Новых нет.

## Этапы

### Этап 25. Набор иконок
**Сделан.** `IconPaths.kt` и `AppIcons.kt` сгенерированы скриптом прямо из массива `ICONS` хэндоффа — руками пути не перепечатывались. Отличия от плана: тест не меряет границы путей (для этого нужен Android `Path`, на JVM его нет) — проверяет, что каждый путь разобрался и начинается с «move», границы сверены глазами на эмуляторе; замок фиксации струны на Live **не** перерисован — это залитый глиф 12 dp внутри значка-бейджа, контур 1.8 в таком размере превращается в кашу; плеер сессии оставлен с залитыми ▶ / ❚❚ на акцентной кнопке — контурный треугольник на заливке терялся бы (иконки `Play` / `Pause` в наборе есть, не используются); токен — `ViolinTheme.destructive` (тот же hex, что `formError`, который остался у формы).
1. `feat(ui): icon set from the handoff` — `IconPaths`, `AppIcons`, `AppIcon`, `IconLabel`, тест на все пути; токен `destructive`.
2. `feat(nav): tab icons with a filled selected state` — вкладки, точка «занятие идёт» по размерам макета, удаление `ic_nav_*.xml`.
3. `refactor(ui): icons drawn in place give way to the set` — «назад» (сессия, произведение, форма, пюпитр), корзина и подложки пюпитра, шевроны календаря и чипа статуса, замок, часы, плеер, плюс на плитке, заглушка миниатюры.

### Этап 26. Иконки у действий
**Сделан.** Отличия от плана: «лучший» — звезда **внутри** чипа перед словом, а не вместо него (цвет дублируется формой и словом); в форме произведения крупное значение степпера осталось «♩ = 96» — метроном встал только в строках на карточке и экране произведения; онбординг и состояние «нет разрешения» не тронуты — там уже есть иллюстрации, а NoMicPermission — это Live; выбранный пункт меню статуса получил галочку.
1. `feat(ui): icons beside text actions` — сессия («Переименовать», «Удалить»), произведение («Изменить», меню фото, «Добавить заметку»), форма («Удалить произведение»), «Записи» («Добавить произведение», нота «дубль»), дубли (звезда), темп (метроном), «Занятия» (старт, стоп, «Изменить / Добавить время», огонёк), профиль («Выбрать / Убрать фото»), «Трофеи», «Настройки», онбординг и «нет разрешения» (микрофон — если там сейчас нет иллюстрации).

### Этап 27. Движение «Занятий»
**Сделан** двумя коммитами вместо трёх (точка и докрутка живут в одном файле экрана). Отличия от плана: «убрать анимации» приходит не параметром экрана, а `LocalReduceMotion` (`core/ui/motion`), который ставит `PracticeRoute`, — иначе флаг пришлось бы тащить через шапку, главное действие и сводку; длительность прохода блика — чистая пропорция пути (landscape выходит ~0.7 с, а не 1.0 с из макета: свет идёт с одной скоростью); разница меньше 5 мин показывается сразу, без затухания 150 мс из макета (спека 0.23 приведена); «Дней подряд» докручивается от скачка в 2 дня — рост на один день показывается сразу. 5 новых unit-тестов на `LevelShineMath` (всего 500). На эмуляторе: блик пойман серией скриншотов (он тихий — α .35 поверх светлого конца градиента), точка и дуга — дуга в 0:27 стоит внизу, как положено секундам; флажок и секундомер на кнопках. Не проверено глазами в движении: дыхание точки, сам проход блика, докрутка чисел, уступка блика росту полосы; «убрать анимации» на этом экране.
1. `feat(practice): a shine travels along the level bar`.
2. `feat(practice): the running dot breathes, a minute ring turns with the timer`.
3. `feat(practice): summary numbers roll to their new values`.
4. `docs:` — spec (отметки «реализовано»), `CLAUDE.md`.

## Риски

- **`PathParser` и дуги**: пути макета полны коротких дуг (`a1.2 1.2 0 1 0 …`); проверяется глазами на эмуляторе по галерее 14a, не только тестом.
- **14 dp**: обводка 1.8 в сетке 24 при 14 dp — ~1 dp; на hdpi может рябить. Если так — мелким знакам поднять обводку до 2.2 в векторе.
- **Блик и перекомпоновка**: значение блика читается только в `drawWithContent`; шапка не должна перекомпоновываться на каждом кадре.
