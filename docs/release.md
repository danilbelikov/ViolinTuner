# Публикация: RuStore, затем Google Play

План выпуска 1.0 (24.09.2026): сначала RuStore, закрытый тест Google Play — параллельно, продакшн Play — после 14 дней теста.

## Этап 1. Код — сделан 24.09.2026

- `applicationId` — `com.violinjourney.app`, навсегда. Debug — `com.violinjourney.app.debug`: встаёт рядом с магазинной, её данных не касается.
- Ключ подписи — `~/keys/violin-journey/release.jks` (PKCS12, RSA 4096, до 2054 г., псевдоним `violin-journey`, `CN=Violin Journey`), пароли — в `local.properties`. SHA-256 сертификата: `AB:A8:E2:CF:8F:B9:38:19:F9:79:F9:62:1D:12:0C:52:67:2E:F9:AB:84:A1:61:21:92:C5:B7:24:E3:28:F9:97`. **Файл и пароль — в двух местах вне этого компьютера** (менеджер паролей, внешний диск): без них обновить приложение нельзя ни в одном магазине.
- Один ключ на оба магазина: в RuStore — подписанный им APK; в Google Play при включении Play App Signing — «использовать свой ключ» (выгрузка через PEPK), а не ключ, созданный Google. Тогда обновление из любого магазина ставится поверх приложения из другого.
- R8 выключен сознательно (APK 17,5 МБ, AAB 16 МБ): включение — задача 1.1 с правилами для Room, Hilt, AppMetrica и полным ручным проходом.
- Строка «Политика конфиденциальности» в «Настройках», блок «Данные» (spec 3.34), ведёт на `https://danilbelikov.github.io/violin-journey/privacy/` — **страницы пока нет**, её создаёт этап 2.
- Проверено: `apksigner verify` (подпись магазинным ключом), 16 КБ — `zipalign -c -P 16` и сегменты `.so` по 0x4000, `lintRelease` — 0 ошибок, unit-тесты зелёные. Release на эмуляторе: знакомство, онбординг, Live, «Настройки», ссылка открывает браузер, «Занятия», дом, «Записи» — без падений. AppMetrica в release активируется с настоящим ключом; эти события с эмулятора ушли в консоль.
- Не проверено: живой звук в release (мост микрофона эмулятора отдавал нули — «Микрофон недоступен», как и в debug); что события release видно в консоли AppMetrica.

Сборка: `./gradlew :app:assembleRelease` (APK для RuStore), `./gradlew :app:bundleRelease` (AAB для Play). Каждая загрузка в любой магазин — `versionCode` + 1.

## Этап 2. Материалы (общие) — черновики готовы 24.09.2026

- Сайт — `docs/store/site/`: главная (что за приложение, два языка, значок) и политика `privacy/index.html` (русский и английский, без сторонних запросов). Единственная копия политики — здесь; репозиторий `violin-journey` — её копия, не наоборот.
- Выкладка сайта:
  1. Вписать в `docs/store/site/index.html` и `privacy/index.html` email, имя разработчика и дату публикации (заглушки в квадратных скобках).
  2. На GitHub — новый **публичный** репозиторий `violin-journey` (пустой, без README).
  3. `git clone git@github.com:danilbelikov/violin-journey.git ~/violin-journey`
  4. `python3 tools/store/site.py ~/violin-journey` — копирует папку; откажется, пока в страницах остались заглушки.
  5. `cd ~/violin-journey && git add -A && git commit -m "The site and the privacy policy" && git push`
  6. На GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main`, `/ (root)` → Save. Через минуту-две страница открывается по `https://danilbelikov.github.io/violin-journey/privacy/` — этот адрес зашит в приложение.
  7. Проверить ссылку «Политика конфиденциальности» в «Настройках» приложения.
- Тексты карточки, план скриншотов, черновики Data Safety и объяснения foreground service — `docs/store/listing.md`.
- Заодно исправлено: минусовки (`files/backings/`) больше не уходят в системную автокопию — одна-две из них переполняли её лимит 25 МБ, и автокопия не проходила вся (spec 5.14).
- Скриншоты — 7 кадров на русском и английском, `docs/store/screenshots/` (как переснять — `docs/store/listing.md`).
- Осталось: заполнить имя, email и дату в политике; решение по возрасту аудитории (дети) в Play.

Исходный список этапа:

- Политика конфиденциальности на русском и английском по адресу выше: что уходит в AppMetrica (модель, версия системы, события из spec 5.27, сбои; рекламного ID нет), что остаётся на телефоне (звук, видео, фото нот), автокопия Android в аккаунт Google (база и настройки), как выключить статистику, email для связи.
- Скриншоты 4–8 на русском и английском: сборка `-PfakePitch=true` на эмуляторе.
- Короткое описание (≤ 80 символов) и полное (≤ 4000), на русском и английском. Иконка 512 и баннеры — уже в `docs/store/`.
- Email поддержки, категория «Музыка» или «Образование».

## Этап 4. Google Play

Аккаунт ($25, проверка личности; оплата российской картой не пройдёт), закрытый тест ≥ 12 тестировщиков 14 дней подряд, AAB с Play App Signing и своим ключом. «Контент приложения»: Data Safety (действия в приложении, сбои и диагностика, ID устройства AppMetrica; шифруется при передаче; сбор можно выключить), объяснение foreground service `dataSync` с видео копии, возрастная анкета IARC, аудитория не дети, рекламы и входа нет. Затем отчёт автоматического теста и продакшн.
