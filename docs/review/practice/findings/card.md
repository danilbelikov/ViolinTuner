## card-04 · заметно · факт · adjusted
- **Где:** 17-idle-top-true.png (карточка 183,6–412,2 dp), 22-small-top.png, 25-small-running.png; JourneyWindowCard.kt:63, 88–104
- **Проблема:** Карточка высотой 228,6 dp вместо 160 dp по макету. Строка, таблетка и полоса стоят отдельной полосой под картинкой (68,6 dp), а в макете они лежат на градиенте поверх картинки. На маленьком экране во время занятия «Закончить занятие» уходит под сгиб (25), над сгибом остаётся только таймер. - **Доказательство:** Пересчитал по пикселям 17 (2,625 px/dp): карточка y 482–1082 px = 228,6 dp, картинка 482–902 = 160,0 dp, полоса под ней 902–1082 = 68,6 dp, нижняя панель с y 2127 px (810 dp), видимая область ≈767 dp. Серьёзность снижена с «блокера»: в PROMPT.md обрезка не названа блокером, многоточие штатное, раскладка цела, смысл «хватает» дублируют цвет таблетки и полная полоса.
