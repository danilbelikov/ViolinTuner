## Навигация: четыре вкладки

- Значок — лист нот по геометрии `i-sheet` в стиле `TabPath`: тело `FILL`, три линии нотоносца и головка ноты `CUT`, обводка 1.8, как у соседей. Три прежних значка — из кода: наброски на страницах, кроме `components.html`, их не заменяют.
- Корень вкладки — нынешний `SectionsList` с «временем по элементам» (колонки landscape — как в коде, по 3.28; новый вид — R4). Эффекты разделов переезжают из `HistoryRoute` в новый `SectionsRoute`.
- «Записи»: переключатель «Записи | Репертуар» и `HistorySection` уходят **в R1**. `HistorySectionAsk` удаляется; «Открыть репертуар» с Live → `navigateToTopLevel(REPERTOIRE)`; `popUpToSection` без раздела в стеке падает на вкладку `REPERTOIRE`, а не `HISTORY`.

## Landscape и маленький экран

Общее правило (записать в `redesign.md`, R1; нарисовано: `landscape.html`, `practice-extra.html`, events-views — экран события):

1. Колонки и их ширины остаются, как в коде сейчас (`PracticeScreen` 280, `PieceScreen` 300, `SessionScreen` min(½, 456), `SoundScreen` 340, `JourneyScreen` 360, `HomeScreen` 320, `HistoryScreen` 360 — у вкладки «Записи» и, после R1, у вкладки «Репертуар»); что в какой колонке — меняет этап по своему макету.
2. **Dock принадлежит колонке, к которой относится главное действие; по умолчанию — левой.** Он шириной с неё, закреплён у её низа, затухание — только над ней; другая колонка прокручивается до низа экрана. Исключение — экран события: dock в правой колонке, под записями (events-views). Затухание: 28 dp; 16 — левая колонка «Занятий» (над кнопкой всего 236 dp); 0 — колонка, которая не прокручивается (дом: три кнопки строкой под комнатой; видео записи над плеером).
3. Одноколоночные экраны (формы, настройки, копия, «Выступления») — колонка по центру не шире 560 dp, dock той же ширины и над клавиатурой. Если между шапкой и клавиатурой меньше 200 dp — dock становится строкой «причина · кнопка 48».
4. Листы — **все** не шире 640 dp по центру, итог (`RecapSheet`, сейчас 560) тоже; внутренние landscape-раскладки из кода (`BlockSheet`, `GiftSheet`, `PracticeSheets`, `ForgottenPracticeDialog`) сохраняются внутри этой ширины. Строки листа — 56 dp.
5. При высоте окна ≤ 360 dp dock не выше 64 dp (кнопка 48).
6. **«Занятия» в landscape — по `practice-extra.html`**: левая колонка 280 — «Сегодня» (число 28 sp, «Неделя» в его строке, столбики 32), под ним напоминание о событии (R9) — без прокрутки (3.35); при идущем занятии — таймер 48 sp и подход, напоминание, ниже столбики недели без карточки; внизу dock «Начать» / «Закончить занятие» с затуханием 16. Правая колонка прокручивается: **строка пути** (в одну строку), окно дома 96 dp (картинка слева, строка справа), календарь. «Вернуться к Live» в landscape нет — её роль играет вкладка Live. Кадры 10j (3.12) и 11g (3.13) этим заменяются.
7. **Маленький экран 360×640 — по `practice-extra.html`**: кнопка в dock и панель видны всегда; кнопка не сжимается (56), поля dock 8 / 16 / 10. «Сегодня» не ужимается (число 40 sp, столбики 48) и целиком на первом экране. Первым сжимается окно дома: картинка = min(148 dp, высота окна прокрутки − блоки над окном − строка окна 56 − 12); ниже 72 dp окно становится строкой 56 dp с миниатюрой 40 (скругление 10). Считать в одном `Layout` по высоте окна прокрутки, а не через `onSizeChanged` — иначе первый кадр мигнёт картинкой 148. «Хватает до Праги — в путь» — перенос после тире (неразрывный пробел перед «в путь», `maxLines = 2`); подпись строки пути — в две строки, не многоточием. Напоминание о событии при высоте окна < 700 dp — компактное (events-views).
8. Каждый этап проверяет: `wm size 720x1280` + `wm density 320`; landscape 892×412 и 640×360 (`user_rotation 1`); `fontScale` 1,3; de и fr. «Занятия» в landscape — ещё с вырезом камеры сбоку и трёхкнопочной навигацией: напоминание видно без прокрутки (над кнопкой меньше 236 dp). Формы в landscape — клавиатура не уходит в полноэкранный режим (`IME_FLAG_NO_FULLSCREEN`), иначе dock не виден.
