# Планы этапов редизайна R5–R8

Планы реализации, написанные до кода (28.09.2026) по подразделам спеки 3.36.5–3.36.8 (`docs/spec/redesign.md`) и коду того дня. Они старше кода: номера строк и имена API в них надо сверять с текущим кодом, а сделанное в R1–R4 (общие части, листы, формы) — брать как есть. Где план спорит со спекой, прав раздел спеки.

| Файл | Этапы | Подраздел спеки |
|---|---|---|
| `plan-r5.md` | 111–113, «Записи» | 3.36.5 |
| `plan-r6.md` | 114–116, Live | 3.36.6 |
| `plan-r7.md` | 117–119, путешествие и дом | 3.36.7 |
| `plan-r8.md` | 120–122, знакомство, онбординг, «Настройки», копия | 3.36.8 |

Для R9 (события, этапы 96–99) первым шагом пишется `docs/plan-events.md` (3.36.9, «Этапы»).

`redesign-stage.workflow.js` — сценарий конвейера одного этапа для Claude Code (инструмент `Workflow`: реализация → ревью четырьмя линзами с проверкой каждой находки → правки подтверждённого); параметры этапа передаются в `args` (`stage`, `heading`, `specBlock`, `scope`, `context`, `check`, `lenses`). Проверку на эмуляторе, инструментальные тесты, iOS и коммит после конвейера делает ведущий — порядок в `docs/notes/redesign.md` у каждого этапа.
