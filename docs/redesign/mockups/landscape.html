Violin Journey · Landscape экранов с закреплённой нижней зоной

Задача: показать одно правило поворота для всех экранов, у которых в новом дизайне главное действие закреплено внизу (dock): куда встаёт dock, когда колонок две, что прокручивается и где кончается затухание. Пять экранов нарисованы целиком, остальные сведены в таблицу. Для кого: скрипач, у которого телефон лежит на пюпитре боком или в руках двумя руками; разработчик, который переносит landscape-ветки кода (BoxWithConstraints) на новый язык. Допущения: экран 892 × 412 dp (базовый 412 × 892 хэндоффа, повёрнутый), строка состояния 24 dp, жестовая полоса снизу 14–20 dp, 1 px макета = 1 dp. Колонки и их ширины — как сейчас в коде: 360 (вкладка «Репертуар»), 300 (произведение), min(½ экрана, 456) (запись), 320 (дом), 560 (формы). Данные — те же, что на соседних страницах: сегодня воскресенье, 27 сентября, 18:42; 47 884 такта; «Концерт ля минор, 1 ч.», «Менуэт соль мажор», «Юмореска». Иллюстрации не перерисованы: комната — снимок с эмулятора из journey-home.html, ноты и видео — заглушки базовых страниц.

  • Выделено: на каждом экране одна крупная залитая кнопка — dock. Второе выделение есть не везде: лучший дубль (слабое, пилюля) или подарок с маленькой «Забрать» (как в портрете journey-home.html). Третьего нет нигде.
  • Высота: при 892 × 412 главное действие видно на всех экранах без прокрутки. На 640 × 360 (самый низкий landscape) — см. «Для реализации» (плитки в один столбец, строка из трёх кнопок дома — от 440 dp) и «Открытые вопросы».

Для реализации

  • Токены: новых нет. Используются --bg, --surface, --surface-2, --text-2/3, --accent, --on-accent, --accent-soft, --t3. Стекло над картинками — 0,72, строгое — 0,82, без размытия. Затухание dock — 28 dp к --bg по умолчанию (исключения — ниже). Формы — 12/18/24/28.
  • Общий компонент R1: колонка с dock — Column { прокрутка(weight 1f); AppDock(fade = 28.dp, aboveKeyboard = …) }, в core/ui модуля shared; fade: Dp = 28.dp, 0.dp — без затухания. Исключения: 0.dp — неподвижная колонка (дом и видео-дубль в landscape); 16.dp — левая колонка «Занятий» в landscape (practice-extra.html). Dock — в колонке, к содержимому которой относится главное действие, по умолчанию в левой; исключение — экран события: в правой, под записями. Колонка без dock — обычная прокрутка с padding(bottom = 16.dp).
  • Панель: AppBottomBar.CompactBar — четыре пункта, SpaceEvenly, пилюля 48 × 32, подпись 12 sp справа. Цель касания пункта — вся высота панели, 64 dp (clickable на fillMaxHeight); пилюля и подпись остаются как есть, вид не меняется. Превью на 640 и 892 dp — в AppBottomBarPreviews.kt.
  • Шапка поверх вкладок в landscape — 48 dp (как TopBarHeightLandscape в PieceScreen). Меняется SessionScreen (56 → 48), JourneyTopBar в доме, форма.
  • Вкладка «Репертуар» (landscape-ветка переезжает из HistoryScreen в новый экран вкладки): слева sectionItems (weight 1f) и dock «Добавить в репертуар», справа PieceTimeCardView шириной LandscapeChartWidth = 360 с TIME_ROWS_LANDSCAPE = 5. Плитки landscape — 72 dp, значок слева; свои разделы — строками под ними, верх первой выглядывает из-под затухания. Если левая колонка уже 320 dp (экран 640), плитки встают в один столбец.
  • Произведение (PieceScreen.LandscapeLayout): TopBar(titleVisible = true). HeaderBlock без названия. Слева 300 (LandscapeLeftColumn): мета, статус, SheetsBlock лентой (Metrics.Landscape, плитки 66 × 88), dock записи. LandscapeRecordButton 64 → кнопка dock 56. Справа: Row(BackingCard weight 4f, NotesBlock weight 3f) — название минусовки не обрезается, заметка — две строки, — если есть оба, иначе каждый на всю ширину; затем TakeProgressCard и TakesBlock.
  • Запись (SessionScreen.LoadedContent): landscape = width > height && content.hasAudio, а не только при picture != null. Левая колонка — minOf(width / 2, 456.dp): картинка (или Summary в сжатом виде) и PlayerAndSound закреплён снизу. Высота видео — колонка − плеер. Справа: Summary (если есть видео), PianoRoll 156 dp, «Что уходит», «По струнам», действия. Прилипания видео в landscape нет.
  • Дом (HomeScreen, ветка maxWidth > maxHeight): слева Column(weight 1f) { Picture(weight 1f); строка «В дорогу» (weight 1f) · «Лавка» · «Обставить», 56 dp } — строка и есть AppDock(fade = 0.dp): комната не прокручивается. Справа 320: имя, счёт вещей, подарок, следующий дом. Строка из трёх — при ширине колонки от 440 dp. Уже — «В дорогу» сверху, «Лавка» и «Обставить» половинками, как в портрете.

Если между шапкой и клавиатурой меньше 200 dp, dock переходит в строку «причина · кнопка 48 dp». Открытые вопросы

  • На 640 × 360 левая колонка произведения даёт под мету, статус и ленту ~144 dp, и лента уходит под затухание. Предлагаю на высоте меньше 380 dp прятать строку «А. Вивальди · a-moll · ♩ = 96» (она есть в «Изменить»). Проверить на эмуляторе.
  • Когда телефон стоит боком на пюпитре, к нему тянутся рукой со смычком. Dock слева — по правилу; стоит проверить на телефоне, удобно ли туда дотягиваться, не отпуская смычок.
  • Проверить на эмуляторе, что клавиатура в landscape не уходит в полноэкранный режим ввода (IME_FLAG_NO_FULLSCREEN у полей Compose): иначе dock над клавиатурой не виден. Клавиатура нарисована высотой 170 dp; у Gboard со строкой подсказок она бывает выше — тогда между шапкой и клавиатурой остаётся ~130 dp: поле в фокусе с подписью (76) и строка кнопки (56) встают впритык; если не встают, подпись поля уезжает вверх при прокрутке.
